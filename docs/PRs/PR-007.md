# PR-007 — scaledBalanceOf read

|Owner|Wave|Label|Complexity|Est|Depends|Branch|Parallel|

## Goal
Eve needs a read-only way to answer "what do I hold?" on Base 8453. This PR adds position reads via `scaledBalanceOf` through the Base MCP connection from PR-005, so the agent reports real onchain balances before quoting or trading anything.

## Scope
- Created: `eve/agent/tools/getPosition.ts`

## Steps
1. Add `getPosition` with Eve `defineTool`: input token symbol (e.g. NVDAc), output human-readable share balance (2 min).
2. Resolve the symbol to its token contract via the venue token allowlist (same list PR-008 quotes against) (2 min).
3. Read `scaledBalanceOf` for the caller's Base Account through the Base MCP read path from PR-005 (chain id 8453) (2 min).
4. Normalize scaled units to human shares using the token's decimals; return zero-balance explicitly rather than erroring (2 min).
5. Combine the onchain balance with the Sibyl WARM basis record for average cost (read-only; writes belong to PR-010/PR-017) (2 min).
6. Return an "unknown token / outside venue" message for symbols not on the allowlist instead of attempting a read (1 min).
7. Test by running `getPosition` against a funded Base 8453 account and an empty one; confirm correct shares and clean zero-balance output (2 min).
8. Register `getPosition` in the Eve agent tool list so instructions/skills can call it (1 min).

## Acceptance
- `getPosition` returns the correct share balance for a venue token on Base 8453.
- Empty accounts return zero, unknown symbols return the outside-venue message.
- No write paths touched; WARM basis is read, never modified.
