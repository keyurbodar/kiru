## Goal
Give Kiru its first memory: a Fly Python sidecar that stores and retrieves conversation state. Eve will later keep pending quotes (HOT) and positions (WARM) here; this PR proves the two core routes work over HTTP.

## Scope
- Created: `sibyl-sidecar/main.py`
- Created: `sibyl-sidecar/requirements.txt`
- Created: `sibyl-sidecar/README`

## Steps
1. Scaffold the FastAPI sidecar in `main.py` with `POST /recall` and `POST /remember` per the PR-000 contract (7 min).
2. Back the routes with local SQLite storage keyed by user and tier (HOT/WARM/COLD) (5 min).
3. Add request validation and error responses matching `contract.md` shapes (4 min).
4. Verify by running the sidecar locally and round-tripping a `remember` then `recall`, asserting the stored value returns (4 min).

## Acceptance
- Sidecar runs locally with two routes: `POST /recall`, `POST /remember`.
- `remember` then `recall` round-trips the same payload.
- Request/response shapes match the PR-000 Sibyl contract.
- `search` and `record` routes are explicitly out of scope.
