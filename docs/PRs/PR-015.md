## Goal
A trading thread should feel like texting a friend, not polling an API. This PR adds tapback reactions, typing indicators, and markdown receipts to the Photon channel so quotes, fills, and errors read naturally in iMessage.

## Scope
- Touched: `eve/agent/channels/photon.ts` (tapback, typing, markdown receipt formatting)

## Steps
1. Send typing indicator while `quoteBuy`/`executeBuy` are in flight, clearing it when the reply sends (3 min).
2. React with tapbacks: acknowledge the user's order text, celebrate fills (3 min).
3. Format receipts as markdown: fill confirmations, decline notices, error/SMS-fallback text (3 min).
4. Verify by texting a buy, a sell, and a bad symbol in the dev thread and confirming typing shows, tapbacks land, and receipts render as markdown (4 min).

## Acceptance
- Typing indicator shows during quote/execute and clears on reply.
- Tapbacks acknowledge orders and fills in-thread.
- Receipts (fill, decline, error) render as markdown.
