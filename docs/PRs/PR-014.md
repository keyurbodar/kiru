## Goal
Quotes and fills deserve richer rendering than plain text. This PR ships the Mini App portfolio card that renders the live quote in-thread and flips from approve to Filled once the order settles, closing the card round-trip back through Photon.

## Scope
- Created: `miniapp/stocks/card/page.tsx` (quote/approve/filled card states)
- Touched: `eve/agent/channels/photon.ts` (card round-trip: send card, receive flip trigger)

## Steps
1. Build the quote state of `page.tsx`: token, amount, venue price, approve button wired to the `approvalUrl` flow (6 min).
2. Build the Filled state: filled shares, average price, new position summary (4 min).
3. Wire the card round-trip in `photon.ts`: render card in-thread, flip approve→Filled on `get_request_status` settled (5 min).
4. Verify by driving a mock buy in the dev thread: card renders, approve flips to Filled, portfolio totals match `getPosition` (5 min).

## Acceptance
- Mini App card renders live quote with approve button in the iMessage thread.
- Card flips approve→Filled on settlement with correct fill details.
- Portfolio totals on the card match `getPosition` output.
