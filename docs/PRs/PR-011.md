# PR-011 — send_calls execute poll

|Owner|Wave|Label|Complexity|Est|Depends|Branch|Parallel|
|---|---|---|---|---|---|---|---|
|keyur|3|CORE|4/5|20 min|PR-005;PR-008|pr-011-send-calls-exec|F|

## Goal
Quoting without execution is a demo. This PR wires the prepared Aerodrome route into Base MCP `send_calls` and polls `get_request_status` to completion, keeping user custody via the `approvalUrl` signing flow — keys never touch the server.

## Scope
- Created: `eve/agent/tools/executeBuy.ts`

## Steps
1. Add `executeBuy` with Eve `defineTool`: input is the `quoteBuy` object from PR-008 (venue, pool, legs); the tool never re-derives the route (3 min).
2. Build the Base MCP `send_calls` payload from the prepared route on Base 8453, addressed to the user's Base Account from PR-005 (3 min).
3. Submit via `send_calls` and surface the returned `approvalUrl` so the user signs in their own Base Account (Photon card handoff is PR-013's job) (2 min).
4. Poll `get_request_status` until terminal state: signed → submitted → confirmed; report each transition back to the chat (3 min).
5. Handle decline/timeout/failure terminal states with a clean message and no partial retry — a failed run must re-quote from PR-008 (2 min).
6. Mark the HOT in-progress order state for the run (via the PR-010 memory contract) and clear it on terminal state (2 min).
7. Test by executing a small USDC→token buy on Base 8453 end to end — `send_calls`, `approvalUrl` issued, `get_request_status` polled to confirmed — plus a declined run that exits cleanly (4 min).
8. Register `executeBuy` in the Eve agent tool list behind the approval flow (never auto-called without user yes) (1 min).

## Acceptance
- A prepared quote executes via `send_calls` and polls to confirmed on Base 8453.
- The user signs through `approvalUrl`; server never holds keys.
- Declined/timed-out runs exit cleanly and require a fresh quote.
