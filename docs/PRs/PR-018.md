## Goal
Users shouldn't have to watch prices themselves. This PR adds the Eve scheduled alerts job that dry-runs Aerodrome venue quotes and texts the user via Photon only when a watched token crosses their threshold — never executing, only notifying.

## Scope
- Created: `eve/agent/schedules/alerts.ts` (schedule, threshold check, Photon notify)
- Touched: `eve/agent/tools/getPrice.ts` (reuse venue quote dry-run path)

## Steps
1. Define alert prefs from WARM watchlist entities: token, threshold, direction (4 min).
2. Implement the schedule body: Sugar CLI venue quote dry-run per watched token, compare against threshold (5 min).
3. Notify via `photon.ts` on cross only, with quote summary and no approval or execution attached (3 min).
4. Verify by seeding a watchlist entity, forcing a dry-run cross, and confirming exactly one Photon text arrives and no order is created (4 min).

## Acceptance
- Schedule dry-runs venue quotes per watched token on cadence.
- Photon text fires only on threshold cross, with quote summary.
- Alert runs never create orders or touch HOT pending state.
