## Goal
Eve needs one short skill doc that maps the whole money loop — reads → prepare → `send_calls` — so the agent follows the venue path instead of improvising its own. This PR writes that plugin md and states explicitly that there are no custom gates: venue + token allowlist enforce.

## Scope
- Created: `eve/skills/stocks.md`

## Steps
1. Document the reads step: `getPosition` (PR-007, `scaledBalanceOf`) and `getPrice` (PR-008, Sugar dry-run) are the only balance/price sources (2 min).
2. Document the prepare step: `quoteBuy` (PR-008) builds the Aerodrome route; the agent must execute exactly that route, never a re-derived one (2 min).
3. Document the execute step: `executeBuy` (PR-011) via Base MCP `send_calls`, polled with `get_request_status`, signed through the `approvalUrl` flow (2 min).
4. Document settlement: USDC legs on Base 8453 per PR-012 (buy USDC→token, sell token→USDC) (2 min).
5. State the no-gates rule: no custom eligibility/region/limit checks live in the agent — venue + token allowlist enforce; anything off-venue is refused with the outside-venue message (1 min).
6. Test by walking the doc against the PR-007/008/011/012 tool signatures and confirming every referenced tool, field, and flow exists with the same name (no dangling references) (3 min).

## Acceptance
- `eve/skills/stocks.md` covers reads → prepare → `send_calls` with correct tool/field names.
- The no-gates rule (venue + token enforce) is stated explicitly.
- No dangling references to tools or flows that do not exist yet.
