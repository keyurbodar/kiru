# PR-012 — USDC settlement path

|Owner|Wave|Label|Complexity|Est|Depends|Branch|Parallel|
|---|---|---|---|---|---|---|---|
|keyur|3|CORE|3/5|18 min|PR-011|pr-012-usdc-settle|F|

## Goal
Every trade starts and ends in dollars. This PR defines the USDC settlement legs on Base 8453 — buy leg USDC→stock token, sell leg stock token→USDC — so `executeBuy` and its sell counterpart move exactly the quoted amounts with slippage taken from the venue quote.

## Scope
- Touched: `eve/agent/tools/executeBuy.ts` (USDC buy/sell legs + fill recording)

## Steps
1. Pin the USDC contract address on Base 8453 used for all settlement legs (2 min).
2. Build the buy legs (USDC→token) from the `quoteBuy` route so executed amounts match the dry-run quote within its slippage band (3 min).
3. Build the sell legs (token→USDC) as the mirror path for cashing out to dollars (3 min).
4. Pre-check the funding leg balance (`scaledBalanceOf` via PR-007: USDC for buys, token for sells) and refuse before `send_calls` when funds are short (2 min).
5. Route both leg sets through the PR-011 `send_calls` + `get_request_status` + `approvalUrl` flow unchanged (2 min).
6. Record each confirmed fill to the Sibyl COLD journal via the PR-010 `record` route (token, side, shares, price) (2 min).
7. Test by running a small buy then sell on Base 8453; confirm USDC left the account on the buy, returned on the sell, legs match the quote, and both fills are recorded (4 min).

## Acceptance
- Buy moves USDC→token and sell moves token→USDC on Base 8453 within quote slippage.
- Short-funds runs refuse before any `send_calls` is issued.
- Both fills land in the Sibyl COLD journal via `record`.
