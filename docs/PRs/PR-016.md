## Goal
Threads should feel personal and stay debuggable. This PR adds per-user chat wallpaper to the Photon surface and OTel trace spans around channel send/receive so a confusing thread can be traced end to end.

## Scope
- Touched: `eve/agent/channels/photon.ts` (per-user wallpaper, OTel spans on send/receive)

## Steps
1. Store per-user wallpaper preference and apply it when rendering the Photon thread (4 min).
2. Add OTel spans around channel receive, tool call, and reply send with user/thread attributes (4 min).
3. Verify by texting from two dev users with different wallpapers and confirming each thread renders its own wallpaper and emits linked spans (4 min).

## Acceptance
- Each user thread renders its own stored wallpaper.
- Receive, tool-call, and reply-send spans appear linked under one trace per message.
- No wallpaper or tracing change alters message content or flow.
