# PR-008 — Aerodrome quote via Sugar CLI

|Owner|Wave|Label|Complexity|Est|Depends|Branch|Parallel|
|---|---|---|---|---|---|---|---|

## Goal
Prices must come from the execution venue itself, not a parallel feed. This PR adds Aerodrome quoting via the Sugar CLI (`uvx sugar`), so `getPrice`/`quoteBuy` return a real dry-run swap quote on Base 8453 that PR-011 can later execute unchanged.

## Scope
- Created: `eve/agent/tools/getPrice.ts`
- Created: `eve/agent/tools/quoteBuy.ts`

## Steps
1. Set `SUGAR_RPC_URI_8453` to the Base mainnet RPC endpoint the Sugar CLI reads for chain 8453 (2 min).
2. Discover the USDC↔token pool with `sugar pools` (via `uvx sugar`); pick the venue pool with live liquidity, fail closed when none exists (2 min).
3. Get the executable price with a `sugar swap` dry-run for the requested size; parse amount-out, price impact, and pool id from the output (3 min).
4. Return zero-liquidity / stale-pool conditions as a "no quote" result, never a fabricated price (2 min).
5. Shape the dry-run output into the quote object `quoteBuy` hands to PR-011 (`send_calls` input), keeping venue, pool, and legs intact (2 min).
6. Stage the pending quote for the Sibyl HOT slot (pending quote state; written via the PR-010 contract) so approval has something to point at (1 min).
7. Test by running a `sugar swap` dry-run for USDC→NVDAc on Base 8453 and confirming `getPrice`/`quoteBuy` parse it into a matching quote object; confirm illiquid pairs return "no quote" (3 min).
8. Register both tools in the Eve agent tool list (1 min).

## Acceptance
- `getPrice` returns a venue quote sourced from a `sugar swap` dry-run on Base 8453.
- `quoteBuy` output feeds PR-011 execution without re-quoting or reformatting.
- Illiquid pairs return "no quote", never a guessed price.
