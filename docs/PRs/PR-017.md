## Goal
"What's my average cost?" and "why did I buy this?" must always have answers. This PR stores watchlist, per-token cost basis, and thesis notes as WARM entities in the Sibyl sidecar so memory survives across threads and sessions.

## Scope
- Touched: `sibyl-sidecar/main.py` (WARM entity shapes: watchlist, basis, thesis)
- Touched: `eve/agent/tools/getPosition.ts` (read basis/entities for answers)

## Steps
1. Define WARM entity shapes: one record per token with shares held, average cost, watchlisted flag, thesis note (5 min).
2. Write entities on every fill via `remember`/`record`: update shares and average cost, append thesis when the user states one (5 min).
3. Serve reads via `recall`/`search`: watchlist listing, "average cost of X", "why did I buy X" (4 min).
4. Verify by recording a mock fill, asking average cost and thesis back, and confirming `search` returns the entity and `getPosition` matches (3 min).

## Acceptance
- One WARM entity per token holds shares, average cost, watchlist flag, thesis.
- Fills update basis via `remember`/`record`; reads serve via `recall`/`search`.
- "Average cost" and "thesis" questions return stored values.
